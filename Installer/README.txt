HEM STUDIO SUITE - Hybrid Elite Mafia

13-stem processing studio: import up to 13 WAV stems, 8 inserts per track,
the native HEM processors, plugin vault, routing, sessions and stereo export.

- Start it from the desktop or Start menu icon "HEM Studio Suite".
- Pick your sound card under AUDIO / I/O (WASAPI). No sound card = editing,
  sessions and export still work, playback does not.
- Sessions (.xml / .json) and exported mixes are saved where you choose.
  Updating or uninstalling never deletes them.
- Not code-signed: if Windows SmartScreen says "Windows protected your PC",
  click More info, then Run anyway.

Third-party notices and licences are in the Notices folder.
