# hem-studio-suite-native

Native C++ / JUCE project for The Hybrid Elite Mafia Studio Suite.

The verified original source is preserved under `native/` on the reviewed [`ci/windows-native-2025`](https://github.com/The-Hybrid-Elite-Mafia/hem-studio-suite-native/tree/ci/windows-native-2025) branch. Main registers the manually triggered Windows workflow and contains status documentation; select the source branch when running it.

See [actual Windows build status](docs/WINDOWS_BUILD_STATUS.md) and [Actions runs](https://github.com/The-Hybrid-Elite-Mafia/hem-studio-suite-native/actions/workflows/windows-native.yml). A real Windows compile has produced the application, but full build-and-test validation is still in progress. No production or hardware acceptance is claimed.
